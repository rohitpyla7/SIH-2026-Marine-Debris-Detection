## Limitations

1. **Single class**: SubPipe only labels "Pipeline". It is NOT appropriate for multi-class marine debris detection.
2. **Domain mismatch**: Pipeline inspection ≠ debris detection. Transfer learning may help but is not guaranteed.
3. **Sequential data**: Adjacent frames are highly correlated. Naive splits cause leakage.
4. **No depth map**: Physical object dimensions cannot be reliably computed without sonar geometry metadata.
5. **Size**: Full dataset is ~80GB. Use SubPipeMini for initial experiments.
